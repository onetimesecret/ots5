## 第一部分：动画故事板 (V3-Animated)

### 设计理念

将"消失"的概念从空间维度扩展到时间维度。每个故事板展示logo从存在到湮灭的完整过程。

### 1. Fading Echo Animation (5 frames)

**时间线**:
- **Frame 1 (0%)**: 信息诞生 - 中心点和第一道回声出现
- **Frame 2 (25%)**: 首次扩散 - 前三道回声完整可见
- **Frame 3 (50%)**: 完全展开 - 所有7层回声可见（巅峰时刻）
- **Frame 4 (75%)**: 开始消散 - 内层回声淡化，外层仍在扩散
- **Frame 5 (100%)**: 几近消失 - 只剩最外层的微弱痕迹

**应用场景**:
- 网站loading动画
- App启动画面
- 消息发送/销毁过程的视觉反馈

**技术实现**: 可用CSS动画或SVG SMIL实现frame之间的过渡

---

### 2. Vanishing Dot Animation (4 frames)

**时间线**:
- **Frame 1 (0%)**: 坚实的核心
- **Frame 2 (33%)**: 第一层溶解 - 核心开始分裂成粒子
- **Frame 3 (66%)**: 深度溶解 - 多层粒子环可见
- **Frame 4 (100%)**: 归于虚无 - 只剩最外层的微弱粒子

**量子隐喻**: 像观察导致的波函数坍缩，粒子从确定位置扩散到概率云

## 第二部分：字体整合 (V3-Typography)

### 设计原则

Logo不是孤立的符号，它与品牌名称共同构成完整的视觉识别系统。

### 1. Echo Wordmark (水平布局)

**组成**:
- 左：Fading Echo logo（缩小版）
- 右："OTS" 大号字母（极细字重）
- 下：小号标语"ONETIME SECRET"

**适用**:
- 网站header
- 营销物料
- 演示文稿

---

### 2. Dot Wordmark

**特点**:
- Vanishing Dot logo + 品牌名
- 更动态、更科技感
- 适合app界面

---

### 3. Minimal Lockup (紧凑横排)

**特点**:
- Minimal Pulse + 等宽字体"OTS"
- 极其紧凑，适合小空间
- 代码/技术风格

**适用**:
- 终端/CLI界面
- 开发者文档
- GitHub README

---

### 4. Stacked Layout (垂直堆叠)

**组成**:
- 上：Logo居中
- 中："OTS"大字
- 下：全称"ONETIME SECRET"分两行
- 底：标语"Ephemeral Messenger"

**适用**:
- 海报
- 启动画面
- 品牌展示页

---

### 5. Dissolving Text (文字溶解)

**创新点**:
- 字母本身也在溶解！
- "O" 坚实，"T" 开始像素化，"S" 大量碎片化
- 右侧粒子继续消散

**概念深化**: Logo的消散哲学扩展到字体排印

**适用**: 特殊场合的艺术化呈现

## 第三部分：色彩点缀 (V3-Color)

### 设计限制

⚠️ **核心原则**: 保持黑白为主，色彩仅作**语义化点缀**

### 1. Echo - Red Accent (红色危险)

**色彩应用**: 最外层回声为红色

**语义**:
- 红色 = 危险/紧急/即将删除
- 表达"时间即将耗尽"的警告

**使用场景**: 倒计时界面、删除确认

---

### 2. Echo - Blue Accent (蓝色信任)

**色彩应用**: 中心点和第一层回声为蓝色

**语义**:
- 蓝色 = 信任/安全/加密
- 表达"创建时刻的安全承诺"

**使用场景**: 创建新secret、加密成功提示

---

### 3. Echo - Green Accent (绿色安全)

**色彩应用**: 中间两层回声为绿色

**语义**:
- 绿色 = 成功/传递中/安全区
- 表达"消息正在安全传递"

**使用场景**: 发送中状态、传输确认

---

### 4. Dot - Gradient Fade (渐变消散)

**色彩应用**: 从青色（内）→浅青→白色→透明（外）

**效果**: 温度感的消散，从"热"（青色）冷却到虚无

**使用场景**: 高端品牌展示、科技风格界面

---

### 5. Flame - Orange Fire (橙色火焰)

**色彩应用**: 红→橙→黄→白（真实火焰色彩）

**效果**: 写实的燃烧效果

**使用场景**: "阅后即焚"功能的直观呈现

---

### 6. Pulse - Neon Cyan (霓虹青)

**色彩应用**: 青色霓虹光效（带glow）

**效果**: 赛博朋克/科技感

**使用场景**: 暗色主题UI、科技演示

## 第四部分：混合概念 (V3-Hybrid)

### 理念

将不同概念的优势元素融合，创造新的视觉可能性。

### 1. Echo-Dot Fusion (回声-粒子融合)

**组合**: 同心圆（Echo） + 粒子溶解（Dot）

**创新**:
- 内部：完整的同心圆
- 中间：圆环开始破碎成粒子
- 外部：完全的粒子云

**优势**: 兼具回声的和谐感和粒子的量子感

---

### 2. Circle-Lock Combo (圆环-锁组合)

**组合**: One-Time Circle + Dissolving Lock

**视觉**:
- 外圈：断裂的圆环（一次性路径）
- 内部：溶解的锁（安全到消失）

**语义强化**: 双重隐喻——一次性使用 + 加密销毁

---

### 3. Grid-Echo Hybrid (网格-回声混合)

**组合**: Dissolving Grid + Fading Echo

**视觉**:
- 中心：3×3像素网格（数字本质）
- 外围：破碎成粒子后形成回声环

**效果**: 从数字化（grid）到模拟化（echo）的转换

---

### 4. Quantum-Echo (量子-回声)

**组合**: Quantum State + Fading Echo

**视觉**:
- 左：观测态（实心回声）
- 中：叠加态（渐变透明）
- 右：未观测态（概率云）

**科学美学**: 最前卫的物理学诠释

## 第五部分：应用场景 (V3-Context)

**规格**: 180×180px, 圆角40px (iOS风格)

**设计**:

- Fading Echo居中
- 可选：右上角红色通知徽章

**导出**: 需生成多尺寸: 1024×1024 (App Store), 120×120, 180×180

---

### 2. Website Header (网站头部)

**规格**: 800×80px

**布局**:
- 左：Minimal Pulse logo + "OTS"文字
- 右：导航菜单（Create / About / Help）
- 底：1px细线分隔

**响应式**: 移动端隐藏文字，只保留logo

---

### 3. Loading State (加载状态)

**规格**: 300×300px

**场景**: 消息销毁中

**设计**:
- 中心：Fading Echo在"Frame 4"状态（75%消失）
- 下方：状态文字"Message destroyed"

**变体**: 不同frame对应不同状态（创建中/传输中/销毁中）

---

**规格**: 350×200px (标准3.5×2英寸)

- 右下：消散粒子图案（subtle）

**印刷**: 建议使用特殊工艺（烫黑、UV、凹凸）

### 5. Email Signature (邮件签名)

**规格**: 400×100px

**设计**:
- 顶部分隔线
- 左：小logo
- 右：公司名 + 链接

**要求**: 白底黑字（适应邮件客户端）

---

### 6. Social Media Avatar (社交媒体头像)

**规格**: 400×400px圆形

**设计**:

## 技术规范

### 动画实现建议

```css
/* CSS Animation Example - Fading Echo */
@keyframes echoFade {
  0%   { /* Frame 1 state */ }
  25%  { /* Frame 2 state */ }
  50%  { /* Frame 3 state */ }
  75%  { /* Frame 4 state */ }
  100% { /* Frame 5 state */ }
}

.logo-echo {
  animation: echoFade 2s ease-in-out;
}
```

### SVG动画示例

```xml
<circle r="21">
  <animate attributeName="opacity"
           values="1;0.5;0.2;0"
           dur="2s"
           repeatCount="1"/>
</circle>
```

- Logo + 文字的整合

- 响应式适配

### 3. 多概念融合

混合设计证明：不同视觉隐喻可以共存，创造新的语义层次。

### 4. 从设计到实现

V3提供了直接可用的资产和技术规范，缩短了从概念到产品的距离。
